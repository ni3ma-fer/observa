# Observa

Application mobile développée avec Flutter (export FlutterFlow).

## Architecture
- `lib/` : Contient tout le code source métier et l'UI (fichiers `.dart`).
- `lib/flutter_flow/` : Composants et thèmes auto-générés par FlutterFlow.

## Installation du projet
1. Installer Flutter.
2. Cloner ce dépôt.
3. Lancer la commande : `flutter pub get`
4. Exécuter le projet : `flutter run`
